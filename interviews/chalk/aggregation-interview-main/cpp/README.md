# Aggregation Interview

In this problem, you will implement the `Aggregator` class in `aggregates.cpp`, which will ingest a stream of data points and answer aggregation queries efficiently.

## Files

- `aggregates.cpp` - Problem statement and `Aggregator` skeleton
- `main.cpp` - Example usage plus the test suite

## Building and Running

To compile and run the tests:

```sh
g++ -std=c++17 -o aggregator main.cpp
./aggregator
```

Or with optimization:

```sh
g++ -std=c++17 -O2 -o aggregator main.cpp
./aggregator
```
